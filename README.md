## E-commerce Sales Analysis using SQL

## Project Overview

This project analyses e-commerce sales data using SQL to answer business questions and identify sales trends and employee performance.

The goal of this project was to practise SQL analysis and develop the ability to turn sales data into meaningful business insights.
## Business Questions

This project uses SQL to answer business questions related to sales performance, customers, products, orders, and revenue.

The analysis covers:

- Total revenue, orders, customers, and products
- Average order value
- Top-selling products
- Revenue by product category
- Top customers by revenue
- Monthly revenue trends
- Revenue by city
- Repeat customers
- Customers who have never placed an order
- Inactive customers
- Best-selling product category
- Highest and lowest revenue-generating products
- Average products per order
- High-value orders
- Customers with the highest average order value
